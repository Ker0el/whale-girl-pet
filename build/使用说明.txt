鲸鱼娘桌宠
========================================

怎么用
----------------------------------------
双击「鲸鱼娘桌宠.exe」启动。不需要安装，不需要额外装任何东西。
启动后桌宠会出现在屏幕右下角。

    · 左键拖动      移动位置
    · 滚轮          放大 / 缩小
    · 双击          恢复默认大小
    · 右键桌宠      打开菜单
    · 托盘图标      也可以打开菜单；单击可以显示 / 隐藏桌宠

第一次启动时它会挥手打个招呼，用气泡说一句「你好呀」，十秒后
（或者你点一下气泡）就换成平时工作的样子。

挑一个表情之后，它就一直是那张，不会自己变。下次打开还是它。

退出：菜单里点「退出」。找不到菜单时，看屏幕右下角托盘区的图标
（Windows 11 可能把它收在「^」箭头里，拖出来即可）。


加自己的表情
----------------------------------------
把 .gif 文件丢进「蓝色大肥鱼表情包」文件夹，重启桌宠即可。
文件名会显示在菜单和表情列表里，所以起个看得懂的名字。


气泡
----------------------------------------
桌宠说话用的是自己画的小气泡，浮在它上方，尾巴指着它。点一下气泡
就能让它提前消失。

菜单里的「气泡样式…」可以换样式，一共四种：经典蓝、深色玻璃、
漫画白泡、糖果泡。窗口里每种都画了一个真气泡给你看，
点哪个用哪个，选完立刻用它说一句话。选择会被记住。


菜单里的开关
----------------------------------------
    鼠标穿透      打开后点击会穿过桌宠，点到底下的东西
    开机自启      默认开启；关掉后就不再随系统启动
    一言          默认开启；关掉后就不再定时念句子

菜单最下面还有一项「请我喝杯奶茶」，点开是赞赏码。


一言
----------------------------------------
默认开启，每 5 分钟用气泡念一句话，带出处。

菜单里的「一言间隔…」可以改间隔：有 1 / 5 / 15 / 30 / 60 分钟的
快捷按钮，也可以自己填（1 到 1440 分钟）。窗口里还有一个
「来一条看看」，点了立刻念一条，不用等。

句子来自公开的「一言」接口（v1.hitokoto.cn），主站不通时会自动
换用备用接口。这一项是程序里唯一会连第三方服务器的地方，
不想要在菜单里关掉即可。


「素材」文件夹是干什么的
----------------------------------------
可选，平时用不到。只有在「蓝色大肥鱼表情包」文件夹里一个 GIF 都没有时，
桌宠才会拿它里面的 1.gif 当画面。


查余额（可选）
----------------------------------------
菜单里的「查余额」需要你自己的 DeepSeek API Key：
    1. 去 platform.deepseek.com 注册并创建 API Key
    2. 菜单 →「设置 API Key」，粘贴进去保存

不填也完全不影响桌宠使用，只是这项用不了。
Key 用 Windows 系统凭据加密后保存在本机，不会上传到任何地方。

查出来的结果会显示在气泡里：余额、今日消费、当前计费时段。
填了 Key 之后，每到整点它会自动查一次并报给你。

「今日消费」是本机累计值，不是官方账单 —— DeepSeek 只提供当前
余额，没有用量接口，所以程序每 10 分钟采一次余额，把观察到的
下降累加进当天。要准确账单请上 platform.deepseek.com 后台。
