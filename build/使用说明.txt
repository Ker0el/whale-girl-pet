鲸鱼娘桌宠
========================================

怎么用
----------------------------------------
双击「鲸鱼娘桌宠.exe」启动。不需要安装，不需要额外装任何东西。
启动后桌宠会出现在屏幕右下角。

    · 左键拖动      移动位置
    · 滚轮          放大 / 缩小
    · 双击          恢复默认大小
    · 右键桌宠      打开菜单
    · 托盘图标      也可以打开菜单；单击可以显示 / 隐藏桌宠

挑一个表情之后，它就一直是那张，不会自己变。下次打开还是它。

退出：菜单里点「退出」。找不到菜单时，看屏幕右下角托盘区的图标
（Windows 11 可能把它收在「^」箭头里，拖出来即可）。


加自己的表情
----------------------------------------
把 .gif 文件丢进「蓝色大肥鱼表情包」文件夹，重启桌宠即可。
文件名会显示在菜单和表情列表里，所以起个看得懂的名字。


菜单里的三个开关
----------------------------------------
    鼠标穿透      打开后点击会穿过桌宠，点到底下的东西
    开机自启      默认开启；关掉后就不再随系统启动
    点击切换表情  默认关闭；打开后左键单击会随机换一个表情


「素材」文件夹是干什么的
----------------------------------------
可选，平时用不到。只有在「蓝色大肥鱼表情包」文件夹里一个 GIF 都没有时，
桌宠才会拿它里面的 1.gif 当画面。


查余额（可选）
----------------------------------------
菜单里的「查余额」需要你自己的 DeepSeek API Key：
    1. 去 platform.deepseek.com 注册并创建 API Key
    2. 菜单 →「设置 API Key」，粘贴进去保存

不填也完全不影响桌宠使用，只是这项用不了。
Key 用 Windows 系统凭据加密后保存在本机，不会上传到任何地方。
