## 鲸鱼娘桌宠 1.0.0

一个 Windows 桌面宠物。透明、置顶、不抢焦点。**选哪个表情就停在哪个，不会自己变。**

### 下载

`whale-girl-pet-setup-1.0.0.exe` —— 双击安装，**素材已经打进安装包**，装完直接能用。

安装位置默认是**安装程序所在文件夹下的同名子文件夹**（比如 setup 在 `D:\下载\`，就装到 `D:\下载\鲸鱼娘桌宠\`），向导里可以改。卸载走「应用和功能」。

> 装完之后别移动安装目录 —— 开机自启指向绝对路径，移动后需要重新开关一次菜单里的「开机自启」。

### 功能

- **157 个表情**，右键菜单选一个就停在那儿；选择会被记住，重启还是那张
- **透明无边框**，浮在其他窗口之上，不占任务栏，点击不抢焦点
- 拖动移动 · 滚轮缩放 · 双击复位
- **鼠标穿透 / 开机自启 / 点击切换表情** 三个开关
- 可选：查 **DeepSeek 余额、今日消费、当前计费时段**（自己填 API Key，用 Windows 凭据加密后存在本机）

### 环境

Windows 10/11 x64。不需要装 Node.js 或任何运行时。
