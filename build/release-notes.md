## 鲸鱼娘桌宠 1.2.1

一个现代化简单美观的 Windows 桌面宠物。透明、置顶、不抢焦点，**选哪个表情就停在哪个，不会自己变。**

这一版是修 bug —— 桌宠不会再被窗口压住了。

### 下载

`whale-girl-pet-setup-1.2.1.exe` —— 双击安装，**素材已经打进安装包**，装完直接能用。

安装位置默认是**安装程序所在文件夹下的同名子文件夹**（比如 setup 在 `D:\下载\`，就装到 `D:\下载\鲸鱼娘桌宠\`），向导里可以改。卸载走「应用和功能」。

> 装完之后别移动安装目录 —— 开机自启指向绝对路径，移动后需要重新开关一次菜单里的「开机自启」。

### 这次修了什么

- **桌宠不会再被窗口压住**。之前它偶尔会被某个最大化的窗口盖住，而且自己回不来 —— 得重启桌宠，或者点托盘图标收起再显示，才能重新浮到最上面。
  原因是 Windows 并不保证置顶窗口一直待在最上层：别的窗口最大化或切到前台时，系统可能把桌宠挤回普通层级，**却不会清掉它的置顶标记**，所以程序自己完全察觉不到被挤下去了。现在它会每隔几秒重新确认一次置顶状态，被挤下去就自己回来。

### 功能

- **157 个表情**，右键菜单选一个就停在那儿；选择会被记住，重启还是那张
- **透明无边框**，浮在其他窗口之上，不占任务栏，点击不抢焦点
- 拖动移动 · 滚轮缩放 · 双击复位
- **气泡** —— 自绘的小气泡浮在它上方，尾巴指着它，点一下消失；第一次启动会挥手打招呼
- **四种气泡样式**：经典蓝 / 深色玻璃 / 漫画白泡 / 糖果泡，窗口里每种都画一个真气泡给你看
- **一言** —— 默认每 5 分钟用气泡念一句带出处的句子，间隔和句子类型都能改
- **每到整点自动查一次余额**，结果用气泡报给你
- **鼠标穿透 / 开机自启 / 一言** 三个开关
- 可选：查 **DeepSeek 余额、今日消费、当前计费时段**（自己填 API Key，用 Windows 凭据加密后存在本机）

### 环境

Windows 10/11 x64。不需要装 Node.js 或任何运行时。

### 说明

- **一言会联网**：句子来自公开的 [一言](https://hitokoto.cn/) 接口（`v1.hitokoto.cn`），不通时自动换用备用接口（`uapis.cn`）。这是程序里唯一连第三方服务器的地方，不想要在菜单里关掉即可。备用接口不支持按类型筛选，所以主站不通时拿到的可能是任意类型。除此之外只剩查余额会联网，那需要你自己填 Key。
- 素材来自 B 站 UP 主 **「赤风RED」**，经授权用于本桌宠。素材版权归原作者，请勿提取用于其他用途。
- 「今日消费」是本机累计值，不是官方账单 —— DeepSeek 只提供当前余额接口，没有用量接口。
- 计费时段按北京时间判定，内置了 2026 年中国法定节假日表。
